Computer Vision Based Posture Detection

A background desktop utility monitoring user sitting alignment in real-time via camera feed and triggering subtle alerts upon slouch detection.

Download Executable (.exe)

Windows 10 / 11 | CPU Optimized | Privacy-Preserving

Local Processing

All landmark detection logic executes on the client device. Video streams are analyzed frame-by-frame in memory and immediately discarded.

Resource Throttling

Uses MediaPipe keypoint detection running at regulated intervals to maintain low memory consumption and prevent thermal throttling.

Native Desktop Alerts

Dispatches operating system notifications upon persistent slouch verification, incorporating threshold filtering and notification cooldowns.
